🚀 Quick Start Guide

Get started with the URL Shortener API in minutes

1. Register Account

Create a new user account to get started

POST /api/v1/auth/register { "email": "user@example.com", "password": "password123", "first_name": "John", "last_name": "Doe" }

2. Authenticate

Login to receive your JWT authentication token

POST /api/v1/auth/login { "email": "user@example.com", "password": "password123" }

3. Create Short URL

Create your first shortened URL

POST /api/v1/urls Authorization: Bearer <token> { "original_url": "https://example.com/long-url", "custom_alias": "my-link" }

4. Track Analytics

Monitor your URL performance

GET /api/v1/analytics/urls/{id} Authorization: Bearer <token>
