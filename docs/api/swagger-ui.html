🚀 Quick Start

1. Register a new account:

POST /api/v1/auth/register { "email": "user@example.com", "password": "password123", "first_name": "John", "last_name": "Doe" }

2. Login to get JWT token:

POST /api/v1/auth/login { "email": "user@example.com", "password": "password123" }

3. Create a short URL:

POST /api/v1/urls Authorization: Bearer <your-jwt-token> { "original_url": "https://www.example.com/very/long/url", "custom_alias": "my-link" }

4. Access your short URL:

GET /{shortCode} → Redirects to original URL
